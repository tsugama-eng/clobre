# CLOBRE: Closed LLM-Operationalized Batch Reviewing Engine

A 100% local, completely offline, privacy-first academic paper reviewer and manuscript brush-up assistant built with **Streamlit** and **Ollama**.

- **OCRの不正確性について / OCR Inaccuracy**
  PDFを解析する際、OCRの誤認識（文字化けや段組の崩れによるテキストの結合など）に起因して、AIが不正確な指摘（存在しないタイポの指摘など）を行うケースが多く見られます。AIの指摘は必ず元のPDFの該当箇所と照らし合わせて確認してください。
  *When analyzing PDF files, optical character recognition (OCR) errors—such as character corruption or text merging caused by multi-column layout degradation—frequently occur. This may cause the AI to generate inaccurate critiques, such as flagging non-existent typos. Always cross-check the AI's feedback with the original PDF document.*

## 🛠️ Installation Guide

Choose the guide that matches your host operating system. To eliminate multi-platform networking bugs, **running Ollama natively on the host OS is strongly recommended** rather than crossing the WSL2 boundary.

### 🔷 Option A: Windows Native Environment
1. **Install Ollama**: Download and run the official Windows installer from [Ollama's website](https://ollama.com). Alternatively, run the following installation command (from Ollama's website) on PowerShell.
   ```cmd
   irm https://ollama.com | iex
   ```
2. **Install Dependencies (Tesseract & Poppler)**:
   - **Tesseract-OCR**: Download the Windows 64-bit installer from the UB Mannheim repository (https://github.com). Install to `C:\Program Files\Tesseract-OCR`.
   - **Poppler**: Download Windows binaries (e.g., `Release-26.09.0.zip` at https://github.com). Extract and place it so that `C:\Program Files\poppler\poppler-26.09.0\Library\bin` becomes available.
3. **Run Application**:
   ```cmd
   pip install -r requirements.txt
   streamlit run clobre.py
   ```

### 🐧 Option B: Ubuntu (Linux) Native Environment
On Ubuntu, system dependencies can be installed cleanly through the official package manager without managing manual absolute path strings.

1. **Install Ollama**:
   ```bash
   curl -fsSL https://ollama.com | sh
   ```
2. **Install System Dependencies (Tesseract & Poppler)**:
   ```bash
   sudo apt-get update
   sudo apt-get install -y tesseract-ocr poppler-utils
   ```
3. **Code Adjustment for Ubuntu**:
   Since Ubuntu registers these tools globally inside standard binary paths (`/usr/bin/`), you should comment out or delete the manual path definitions inside `app.py`:
   ```python
   # For Ubuntu deployment, comment these out:
   # pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\..."
   # POPPLER_PATH = r"C:\Program Files\..."
   ```
   And modify the text extraction block to omit `poppler_path`:
   ```python
   # Change from: convert_from_path(temp_path, dpi=300, poppler_path=POPPLER_PATH)
   # Change to:   convert_from_path(temp_path, dpi=300)
   ```

### Pulling Recommended Models (Both OS)
Open your terminal/command prompt and pull the models optimized for your VRAM:
```PowerShell or bash
ollama pull gpt-oss:20b
ollama pull gemma4:26b
```

## 🚀 Network & Enterprise Deployment Patterns

### Pattern 1: Local Wireless LAN (Wi-Fi) Sharing
To let members connected to the same research-lab Wi-Fi router access this UI and GPU horsepower:

#### For Windows:
0. Stop the running Ollama process by clicking "^" in the panel next to the clock, right-clicking the Ollama icon, choosing "Quit", and running the following command on PowerShell:
   ```cmd
   stop-process -name ollama -force
   ```
1. Shut down the Ollama tray app completely, then launch via Command Prompt:
   ```cmd
   set OLLAMA_HOST=0.0.0.0
   ollama serve
   [System.Environment]::SetEnvironmentVariable('Ollama_NUM_PARALLEL', '1', 'User')
   [System.Environment]::SetEnvironmentVariable('Ollama_STREAM_TIMEOUT', '1200s', 'User')
   ```
2. Launch Streamlit: `python -m streamlit run clobre.py --server.address 0.0.0.0 --server.enableCORS false --server.enableXsrfProtection false`

#### For Ubuntu (Systemd configuration):
1. Edit the Ollama system service configuration:
   ```bash
   sudo systemctl edit ollama.service
   ```
2. Add the following environment bounds to allow external traffic:
   ```ini
   [Service]
   Environment="OLLAMA_HOST=0.0.0.0"
   Environment="Ollama_STREAM_TIMEOUT=1200s"
   Environment="Ollama_NUM_PARALLEL=1"
   ```
3. Save, reload systemd, and restart the service:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart ollama
   ```
4. Launch Streamlit: `python3 -m streamlit run clobre.py --server.address 0.0.0.0 --server.enableCORS false --server.enableXsrfProtection false`

### Pattern 2: Remote Access via Google Workspace Authentication
If your institution uses Google Workspace, you can safely expose this local UI to the open internet (or home networks) without security risks by mapping it behind **Google IAP (Identity-Aware Proxy)**.
- **Secured Web Access**: Pair a tunnel layer like `cloudflared` with Google Cloud IAP. Anyone clicking the link from home will be met with your university's official Google login panel. Only accounts under your organizational domain (e.g., `@univ.ac.jp`) will be allowed through to communicate with your local machine's VRAM.
